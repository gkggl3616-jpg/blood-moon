# Rogue: Blood Moon v0.1.16 — Bilge native test build

Original Bilge human/wolf meshes integrated with the preserved Human47/Ice40 source skeletons and native key timings. Model-specific 1.933s roar, source-timed hand flames, skin-bound tattoos, short damaging roll and native upper/lower motion selection. Inventory ownership, loadouts, tattoo bonuses and offline arena remain available.

This is a playable test build, not final model acceptance: human wrist/cuff deformation remains visible. Ice40 source running is bipedal. Physical Android installation/performance has not been tested here; no FPS or crash-free guarantee. Further model weighting and visual polish are required before extending the roster.

All runtime models, textures, scripts and media are embedded in one signed APK. Version code 17, same package and required signing certificate as v0.1.15. No separate model pack or data installation is needed.

Build publication requires UI/inventory, arena/combat, four-character regression and native Bilge WebGL checks plus APK asset/signature verification.
