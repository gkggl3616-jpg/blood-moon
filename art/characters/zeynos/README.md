# Zeynoş (onaylı tasarım)

Kurt ve insan formu, kullanıcının onayladığı Higgsfield görselleri (T-poz). 3D model bu görsellerin birebir aynısı olmalı.

- İnsan: beyaz ten, kıvırcık kızıl saç, yeşil göz; dekolteli deri korse, altın tokalı kemer ve çanta, katlı deri etek, diz üstü çizme.
- Kurt: gerçekçi kurt kafası, beyaz kürk, kızıl kıvırcık yele, beyaz kuyruk; aynı korse/etek/çizme.
- İki formda da: kalp kristalli gerdanlık, dirseklerde parlayan pembe kalp kristalleri.
- Rol: iyilik için savaşan, yumuşak karakterli koruyucu. Kükreyince etrafında pembe kalpler; dirsek kristalleri parlar.
